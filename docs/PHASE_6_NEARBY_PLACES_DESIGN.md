## 1. Overview and Engineering Principles

Travellers exploring a destination often want to discover cluster opportunities: nearby sister attractions to visit on the same day, accessible transit hubs to reach or depart the site, local restaurants for authentic Karnataka meals, and verified hotels or jungle lodges.

The Nearby Places module calculates distance dynamically from the authoritative destination latitude/longitude, strictly reusing existing verified datasets without fabricating entities.

---

## 2. Geospatial Proximity Calculation

### 2.1 The Haversine Formula
Straight-line distance is computed via the great-circle Haversine formula implemented in `backend/app/repositories/destinations.py`:

$$\Delta\sigma = 2 \arcsin \sqrt{\sin^2\left(\frac{\Delta\phi}{2}\right) + \cos\phi_1 \cos\phi_2 \sin^2\left(\frac{\Delta\lambda}{2}\right)}$$
$$d = R \cdot \Delta\sigma$$

Where:
- $R \approx 6371.0\text{ km}$ (mean Earth radius).
- $\phi_1, \phi_2$ are latitudes in radians.
- $\Delta\phi = \phi_2 - \phi_1$, $\Delta\lambda = \lambda_2 - \lambda_1$.

### 2.2 Truth in Labeling
- Distances computed by this formula are explicitly labeled as **straight-line distance (ಸರಳ ರೇಖೆಯ ದೂರ)**.
- Distances are rounded to 1 decimal place (e.g., `14.2 km`).
- The application never presents straight-line distances as road driving times. Driving times are exclusively generated by the terrain-adjusted routing service (`backend/app/services/routing/`).

## 4. API Specification

### Endpoint: `GET /api/v1/destinations/{id_or_slug}/nearby`

**Query Parameters:**
- `radius_km` (float, default: `50.0`): Search cutoff radius.
- `limit` (int, default: `5`): Maximum items to return per sub-category.

**Response Structure (`DestinationNearbyResponse`):**

## 5. UI Presentation & Empty State Handling

In `DestinationModal.tsx`:
1. **Interactive Cards:** Clicking a nearby attraction opens its detail modal directly.
2. **Dual-Language Badges:** Displayed with bilingual badges (e.g., `ಆಕರ್ಷಣೆಗಳು / Attractions`, `ಸಾರಿಗೆ ಸಂಪರ್ಕ / Transit Hubs`).
3. **Empty States:** If no verified restaurants or accommodations are within the immediate 50 km radius, the UI displays a clean message:
   *"No verified listings found within 50 km. (50 ಕಿ.ಮೀ ವ್ಯಾಪ್ತಿಯಲ್ಲಿ ಪರಿಶೀಲಿಸಿದ ಪಟ್ಟಿಗಳು ಲಭ್ಯವಿಲ್ಲ)"*
   No fictitious entities are ever inserted to populate empty lists.
